Para facilitar a visualização e avaliação do código-fonte, os principais arquivos da aplicação foram disponibilizados individualmente neste repositório:

HOME.TSX
INPUT.TSX
DETALHES.TSX
ENERGIA-COTIDIANO.TSX
SUSTENTABILIDADE.TSX
INDEX.TSX
_LAYOUT.TSX

Cada arquivo corresponde a uma das telas ou componentes centrais do aplicativo desenvolvido em React Native com Expo Router.

● Instruções de Execução

Este repositório tem como objetivo apresentar os arquivos-fonte principais utilizados no desenvolvimento da aplicação.

O APK Android foi gerado, testado e entregue conforme solicitado na atividade.

Para executar o projeto localmente, é necessário reconstruir a estrutura padrão de um projeto Expo, posicionando os arquivos nas respectivas pastas da aplicação e instalando as dependências do projeto.

●Funcionalidades

* Tela inicial de acesso ao aplicativo.
* Navegação entre páginas utilizando Expo Router.
* Página principal com informações sobre energias renováveis.
* Página sobre energia renovável no cotidiano.
* Página sobre sustentabilidade.
* Página de detalhes complementares.
* Interface desenvolvida para dispositivos.
